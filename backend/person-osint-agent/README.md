# Person OSINT Agent

Отдельный FastAPI-сервис поиска профилей людей. Локальный порт — **8001**.
Проверка деловых связей руководителей через Checko в экране компании выполняется другим
сервисом — `osint-agent` на порту 8000.

## Установка и запуск

Из этого каталога, Python 3.10+:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
cp .env.example .env
.venv/bin/python -m uvicorn person_osint.main:app --host 127.0.0.1 --port 8001
```

`.env` читается из текущего каталога. После правки настроек перезапустите процесс.
Проверка процесса: http://localhost:8001/health. Swagger: http://localhost:8001/docs.

## Поиск и профиль

1. Отправьте `POST /api/v1/people/search` с `full_name` и фильтрами.
2. Выберите кандидата и конкретные аккаунты из ответа.
3. Передайте их как `selected_accounts` в `POST /api/v1/people/profile`.

```json
{
  "full_name": "Иван Иванов",
  "selected_accounts": {"vk": "123456"}
}
```

Поддерживаются числовой ID VK, логин GitHub, HTTPS-ссылка LinkedIn `/in/...`.
Разные аккаунты однофамильцев сохраняются отдельно. Без выбора аккаунта обычный режим
возвращает ошибку 400. Данные других источников не добавляются только по совпадению имени.
Контракты остальных маршрутов доступны в Swagger.

## Что работает и что ограничено

- Есть сборщики и нормализация профилей, поиск кандидатов и сбор сведений выбранного человека.
- VK требует `VK_SERVICE_TOKEN`, LinkedIn — `PROXYCURL_API_KEY`; Checko — `CHECKO_API_KEY`.
- Отсутствие ключа не включает демонстрационные данные автоматически.
- Санкции, суды и долги этого сервиса пока не подключены: состояние `unavailable`.
- `null` в `is_sanctioned` или `is_pep` означает «не проверено».
- `source_statuses`: `ok`, `not_found`, `not_checked`, `unavailable`, `error`, `demo`.
- Некоторые экраны поиска людей скрыты в навигации основного UI. Наличие API не означает завершённый продуктовый сценарий.

`DEMO_MODE=true` явно включает тестовые данные; ответы помечаются `is_demo=true`.
Для реальных проверок оставьте `DEMO_MODE=false`.

## Проверки

```bash
.venv/bin/python -m pytest tests/unit tests/integration -q -m 'not integration_real'
```

Нужен тестовый `.env`. Текущая проверка: 145 тестов прошли.
Это тесты кода и ответов с подменёнными внешними сервисами; доступность VK/LinkedIn
и других внешних поставщиков они не подтверждают.
