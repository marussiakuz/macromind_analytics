# Интерфейс MacroMind Analytics

Одностраничное приложение на JavaScript без React/Vue. Сборка — Vite, стили — Tailwind CSS.
Это прототип с сочетанием реальных API и демонстрационных экранов.
Общий статус — в [главном README](../README.md).

## Запуск

Из этого каталога:

```bash
npm ci
cp .env.example .env
npm run dev
```

Откройте http://localhost:5174. Демо-доступ указан на экране входа.
Он переключает интерфейсные роли и **не является серверной авторизацией**.

```bash
npm test
npm run build
npm run preview
```

`preview` показывает собранный интерфейс, но не заменяет серверы API.
Порт 5174 задан в `vite.config.js`; занятый порт Vite может заменить следующим.
CORS основных API разрешает порты 5174, 5173 и 3000 на localhost/127.0.0.1.

## Что получает реальные данные

- «Фонд → Проверить юр. лицо»: Checko через основной API на `localhost:8000`.
- Финансы, история событий, реестры и связанные физлица — через тот же API.
- Анализ рынка загружается из сохранённой версии либо создаётся новым исследованием.
- Поиск доказательств и сигналы базы знаний — `/api/v1/knowledge/*`, нужен отдельный доступ.
- Поиск профилей людей использует отдельный API на `localhost:8001`; часть навигации скрыта.

Заявки стартапов, проекты воронки, некоторые сводки и сигналы ещё используют `src/data/*`.
Не считайте заполненный демонстрационный экран подтверждением серверной реализации.
История проверок браузера хранится локально; это не общая история пользователей фонда.

## Карта кода

| Каталог / файл | Назначение |
|---|---|
| `src/main.js` | Запуск приложения |
| `src/state.js` | Общее состояние интерфейса |
| `src/events.js` | Основные обработчики, запросы проверки компаний и людей |
| `src/api/` | HTTP-клиенты: компании, финансы, реестры, рынок, знания |
| `src/render/` | Разметка экранов; `market.js` — рыночный отчёт |
| `src/market/` | Состояние, события и проверка структуры рыночного отчёта |
| `src/checkHistoryStore.js` | Локальное сохранение истории проверок |
| `src/data/` | Демонстрационные данные и сценарии |
| `tests/` | Тесты клиентов API, сохранения и отображения результатов |

## Настройки и ограничения

Основные адреса API пока заданы в исходниках. Для другого хоста нужно согласованно изменить
`src/events.js`, значения по умолчанию в `src/api/` и CORS серверов. Один параметр Vite пока
не переключает все клиенты.

`VITE_KNOWLEDGE_API_KEY` в `.env` попадает в браузер и в собранный JavaScript.
Для локального прототипа допустим отдельный ограниченный пользовательский токен из
`KNOWLEDGE_USER_ACCESS`. **Не используйте внутренний сервисный токен или ключи внешних API.**
Перед эксплуатацией требуется полноценная схема пользовательской авторизации.

Ошибки доступа к источникам показываются как ошибки. Отсутствие данных не означает
отсутствие риска. Не заполняйте пустые разделы демонстрационными выводами при сбое API.

Сборка пока содержит крупный JS-пакет: импорт всего набора Lucide и библиотек графа
требует дальнейшего разделения загрузки. Предупреждение сборщика зафиксировано в проверках.
