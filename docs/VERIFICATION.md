   Основной API импортирует его при старте, поэтому отсутствие зависимости ломало чистую установку.
3. Добавлен `npm test`.
4. Переписаны четыре README. Удалены неверные утверждения о полностью демонстрационном UI,
   обязательном запуске всей Docker-композиции и готовой универсальности отчёта.
5. Добавлены `docs/DEVELOPMENT.md` и `docs/HANDOFF.md`, дополнены образцы настроек.
6. Два WHOIS-теста из unit-набора обращались в сеть. Один падал по тайм-ауту.
   Теперь они используют фиксированный ответ на границе сетевого вызова и проверяют обработку,

   Путь привязан к файлу теста, пропуск по произвольной ошибке убран.
8. В импорте Incognita стандартные папки больше не привязаны к имени пользователя рабочей станции.

## Что эта проверка не подтверждает

- Полный живой отчёт по новой компании с актуальными ключами, проверенными конкурентами и рыночными оценками.
- Запуск PostgreSQL/pgvector, миграций, обработки очереди и модели векторизации в новой инфраструктуре.
- Качество ответов базы знаний и полноту её корпуса.
- Работу удалённых серверов, домена, маршрутизатора, резервного копирования и восстановления.
- Доступность каждого метода Checko и всех источников поиска людей.
- Готовую серверную авторизацию фонда/стартапа, хранение заявок и полную защиту для открытой эксплуатации.

Пропущенные проверки нельзя считать прошедшими. Демонстрационные экраны и сохранённые локальные
отчёты не считаются подтверждением нового живого анализа.

## Воспроизведение

Для обычной разработки используйте команды из README и тестовый `.env`.
Для проверки чистой установки создайте новое окружение вне проекта и запускайте тесты из
пустого каталога. Указывайте абсолютные пути к исходникам тестов, например:

```bash
# Из корня репозитория; сначала сохраните его абсолютный путь:
MMA_REPO_ROOT="$PWD"
python3 -m venv /tmp/mma-review-venv
/tmp/mma-review-venv/bin/python -m pip install -e "$MMA_REPO_ROOT/backend/osint-agent[dev]" -e "$MMA_REPO_ROOT/backend/person-osint-agent[dev]"
cd /tmp
/tmp/mma-review-venv/bin/python -m pytest "$MMA_REPO_ROOT/backend/osint-agent/tests/unit" "$MMA_REPO_ROOT/backend/osint-agent/tests/knowledge" "$MMA_REPO_ROOT/backend/osint-agent/tests/integration/test_full_pipeline.py" -q
```

Проверки PostgreSQL запускать только против отдельной тестовой БД.
В этом прогоне тестовая PostgreSQL и модель векторизации не были подготовлены.
